# EYE // TAIWAN v0.28.0 — Target CCTV + National Flow

Base: v0.27.0 Free Immersive + Taiwan CCTV Search

## Changed
- Startup always returns to Taiwan full-island national analysis after the boot animation.
- Explicit `view=shared` is now required to restore a local shared target.
- CCTV UI/API no longer exposes location-only cameras without viewable image streams.
- Every searched target gets a coordinate-specific twipcam nearby-CCTV link; CCTV results also expose tw.live nearby discovery.
- A11 and full-name variants resolve locally to 新光三越台北信義新天地 A11, 松壽路 11 號.
- NAV mode displays only A/B planning controls; an existing searched target populates B.
- Freeway flow rendering uses stronger color visibility and `SectionStart`/`SectionEnd` geometry fallback when SectionShape is unavailable.
- Last successful freeway flow remains visible during a transient refresh failure (`STALE`) instead of disappearing.

## Preserved
- v0.27 FREE 3D navigation and GPS follow.
- Existing command-room visual design.
- Zero-key data path and Vercel Hobby 2-function architecture.
- Original parity features, sensor looks, cockpit, route, weather, traffic, AQI, flood, parking, construction, flights, quakes and news.
