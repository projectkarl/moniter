# EYE // TAIWAN v0.30.0 — Clean Navigation + CCTV Vision Lab

Base: v0.29.0 Full Ops + Inline CCTV.

## Navigation cleanup
- Switching from NAV back to 地點監控 now stops active GPS navigation and removes route geometry, alternate-route geometry, route choices, route threat state and time-machine state.
- Ending navigation clears A/B navigation fields, closes navigation-only state, returns to monitor mode and then restores the Taiwan-wide startup view.
- Public speed-enforcement markers are no longer mounted in normal monitor/national maps. The SPD layer is exposed only while active driving navigation is running.

## CCTV experience
- Added in-page CCTV enlarge mode; double-clicking the live CCTV or pressing `⛶ 放大` expands the existing live feed without opening another site.
- Existing VD/freeway flow Sensor Fusion is mirrored into the main inline CCTV card instead of remaining primarily in the legacy camera drawer.
- Added `VISION LAB`, an optional browser-side, zero-key, single-frame object analysis path loaded only on demand.
- VISION LAB detects only broad object classes used for situational awareness: person, car, bus, truck, motorcycle and bicycle.
- It derives a visual crowd-density index and traffic-density index from one frame. These are estimates, not headcounts or official occupancy measurements.
- No face recognition, plate OCR, identity inference, cross-camera tracking, vehicle brand recognition or precise vehicle-model recognition is provided.

## News
- Target news stays concise by default and can expand in-place with `看更多`; the full news operations view also supports expansion rather than dumping every item immediately.

## Layout / UX cleanup
- Consolidated desktop top offsets so topbar, search, map-layer controls, flow legend and right-side intelligence panel do not compete for the same vertical space.
- Mid-size desktop widths hide the decorative center tagline before controls start overlapping.
- Mobile topbar removes lower-priority network/share labels while preserving core controls.
- Removed duplicated Weather and Ops header DOM that could create inconsistent layout/query behavior.

## Architecture
- Frontend remains zero-key.
- Vercel Functions remain 2: `/api/data` and `/api/cctv-feed`.
- TensorFlow.js / COCO-SSD are loaded from a public CDN only when VISION LAB is explicitly used; they are not part of normal startup cost.
