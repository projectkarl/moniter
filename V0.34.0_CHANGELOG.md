# EYE // TAIWAN v0.34.0 — Search Fusion

## Search accuracy
- Added a verified landmark layer for high-confidence Taiwan shorthand that open geocoders commonly misread.
- `華南總行` / `華南銀行總行` / `華南商銀總行` now resolves to 華南商業銀行總行, 臺北市信義區松仁路123號 (approx. 25.0343, 121.5692).
- Added corporate shorthand expansion for `總行` / `總部` / `總公司` queries.
- Search now aggregates Nominatim + Photon results instead of accepting the first upstream answer blindly.
- Results are re-ranked by query/name similarity, verified-landmark confidence, provider importance, Taiwan bounds, and local bias.
- Location bias can improve nearby searches, but it no longer overrules a strong exact-name match.
- Added coordinate/name deduplication so the same place from two providers does not clutter results.
- Nominatim requests now ask for address details, name details and extra tags to improve display quality.
- Failed public providers no longer prevent a verified local landmark from resolving.
- Empty results now return a useful hint to add city/district/full address instead of a generic failure only.

## Search suggestions
- Added 華南商業銀行總行 to the local POI suggestion catalog.
- Existing aliases for 101, A11, MRT/stations, universities, airports, malls and common landmarks are retained.

## Reliability
- Service worker shell cache bumped to `eye-taiwan-shell-v340` so deployed clients do not keep the older search code.
- Added v0.34 regression coverage that intentionally returns a wrong Kaohsiung Huanan branch from an upstream provider and verifies the Taipei head office still ranks first.
