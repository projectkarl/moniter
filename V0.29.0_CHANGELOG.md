# EYE // TAIWAN v0.30.0 — Full Ops + Inline CCTV

## Restored / exposed original functions

- Preserved original click-to-track, cockpit, Sensor Looks, source provenance, voice markup, annotations, detection overlay and intelligence layers.
- Added visible Advanced Ops entries for MISSION and SENTINEL; SWEEP / WATCH / MISSION / SENTINEL / THEATER now all have UI entry points and handlers.
- Added a UI-handler parity test so future iterations cannot silently leave an operation button without a handler.

## National startup / congestion

- Full-island Taiwan remains the mandatory normal boot state.
- Restored the HOTSPOT CCTV preview that had been hidden by a later CSS override.
- National dashboard ranks slow corridors even when no road reaches the severe-congestion threshold.
- Slow/congested cards show road, speed, reason and nearest playable CCTV distance.
- If the national direct-live registry has no camera within the hotspot radius, a second coordinate-based public-camera lookup is performed and the result is previewed inside EYE.
- Freeway flow retains green / yellow-green / orange / red visualization plus SectionStart/SectionEnd geometry fallback.

## CCTV

- Removed server-side and client-side national camera sampling.
- National safety ceiling increased to 8,000 viewable camera records.
- Added Leaflet Canvas rendering for the national CCTV layer so large marker sets remain clickable without thousands of SVG DOM nodes.
- Position-only/non-viewable records remain excluded.
- Local target/intersection lookup enriches viewable cameras using the public twipcam nearby index.
- twipcam camera records stay inside EYE's camera UI; direct media is resolved when possible, with an in-panel public-page fallback when direct browser media is unavailable.
- Removed normal external-link CCTV discovery from the operator flow.

## Search / navigation

- A11 aliases remain zero-key direct-coordinate matches.
- NAV mode remains A → B only; an already searched monitor target is copied into B.
- Ending navigation returns to the national analysis view.

## Deployment

- Vercel Functions remain 2.
- Service Worker shell cache: v29.
- No paid API or frontend secret added.
