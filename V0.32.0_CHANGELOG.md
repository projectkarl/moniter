# EYE // TAIWAN v0.32.0 — CCTV Stability + Clean Mobile

## CCTV
- Local queries include official CCTV positions even when a direct live stream is unavailable.
- Taipei 101 / target searches refresh nearby official points plus public live-camera index results.
- Taipei 101 has a small verified fallback set (101, 信義松智, 松壽松智, 信義/莊敬, 信義松仁) for upstream timeout resilience.
- Direct-feed failures fall back in-app to the embeddable nearby CCTV widget.
- Position-only markers remain visible and open nearby public imagery rather than disappearing.

## Map stability
- CCTV loading no longer calls `flyTo`.
- CCTV wall auto-selection no longer moves the map.
- User drag/zoom temporarily blocks non-essential programmatic map motion.
- Explicit search and navigation remain allowed to reposition the map.
- Target request sequencing prevents an older async search from overwriting a newer target.

## Mobile simplification
- Bottom dock reduced to Locate / CCTV / Voice.
- Decorative tactical overlays hidden on phone layouts.
- National overview starts compact on mobile.
- CCTV popup keeps a large grab/close header and map-visible margins.

## Cache
- Service worker cache bumped to `eye-taiwan-shell-v320` to prevent old v0.31 assets from persisting after deployment.
