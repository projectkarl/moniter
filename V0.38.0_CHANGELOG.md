# v0.38.0 — Original Source CCTV + Scenic Fusion

- `monitor1.wfuapp.com` is used only as a source-discovery/reference directory; it is never used as the playback iframe or media endpoint.
- Taipei cameras resolve to the official Taipei BOTE source when a camera ID is available.
- New Taipei cameras resolve to the official New Taipei ATIS source when a device ID is available.
- Existing freeway/highway/local-government registry sources continue to use their original public endpoints.
- Place searches now pass the searched place name into the CCTV pipeline so scenic/live-tourism cameras can be fused with nearby road CCTV.
- Scenic cameras are prioritized at the searched target and shown as `SCENIC` live cards on the map, while nearby road cameras remain visible around the target.
- Verified direct scenic sources include Taipei 101 and selected Taoyuan Tourism official live cameras; other places can be resolved dynamically from the reference directory to the underlying official/government/YouTube source.
- If a reference article only exposes an official player page, EYE performs one additional source-resolution pass to find a direct YouTube/HLS/image/video endpoint when possible.
- Third-party reference pages are never used as a playback fallback; unresolved items remain unavailable/position-only rather than embedding the reference site.
- Service-worker cache bumped to `eye-taiwan-shell-v380`.
