# EYE // TAIWAN v0.27.0 — Free Immersive + Taiwan CCTV Search

Base: v0.26.0 Live Navigation Zero-Key

## Added
- Zero-key FREE 3D navigation mode that follows browser GPS and route heading.
- MAP / FREE 3D navigation view switch.
- End-navigation reset: clears route/search fields and returns to Taiwan national mode.
- Direct intersection CCTV search independent of the geocoder.
- Multi-source Taiwan CCTV registry with XML / JSON / CSV / ODS adapters.
- LIVE vs LOC camera classification and per-source health reporting.
- National geographic camera sampling while preserving full-registry text search.
- Same-origin CCTV feed resolution for all registered LIVE sources.

## Zero-key policy
No Google Maps, Google Street View, Google billing account, or paid navigation API is required. FREE 3D is a derived route visualization, not a claim of live photorealistic street imagery.

## Data integrity
A source is marked LIVE only when the public source exposes a playback URL. Government datasets that only publish camera/intersection positions are marked LOC. Offline or unsupported sources are never replaced with fabricated cameras.
