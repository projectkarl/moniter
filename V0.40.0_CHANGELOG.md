# EYE // TAIWAN v0.40.0 — Fast Flow + Progressive CCTV

## Fixed
- Fixed freeway section endpoint parsing where empty XML coordinate fields could become numeric `0` and be treated as valid `[0,0]` geometry, causing Taiwan freeway segments to disappear after distance filtering.
- National flow no longer truncates the network to the nearest 220 segments; national mode can retain up to 1,200 matched freeway sections.
- Heavy `SectionShape.xml` is no longer on the normal first-paint path. `LiveTraffic.xml + Section.xml` render first; shape geometry is only fetched as a fallback when section endpoints are unavailable.
- Nearby road CCTV is no longer blocked by scenic-camera discovery. Road cameras return first; scenic official streams enrich the target asynchronously.
- National CCTV mode now focuses on Freeway Bureau + Highway Bureau original road-camera registries instead of waiting on municipal sources.
- Removed narrow-phone CSS that silently hid CCTV preview cards 3+.
- Search/locate/query buttons are forced back to a dark, high-contrast tactical style.

## Improved
- National board paints progressively: flow, traffic events and CCTV update independently as each source becomes available.
- Added a nationwide network summary strip with segment count, congestion count, slow/normal count and per-road aggregate speed/status.
- HWY mode switches to the clearer tactical street base, expands the national board and keeps flow colors as the primary map layer.
- Degraded flow refreshes no longer erase the last usable flow network from the map.

## Compatibility
- Existing direct CCTV proxy/HLS handling, search fusion, navigation, live location, map-point intel, scenic official sources, original project parity and Vercel Hobby two-function architecture are retained.
