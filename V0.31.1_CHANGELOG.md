# EYE // TAIWAN v0.31.1 — Mobile Usability + Search Recovery

## Mobile
- Further removes map-blocking HUD layers on phones: provenance ribbon and duplicate flow legend are hidden while core map layers remain reachable.
- Very narrow screens compress the national summary so the map stays usable instead of being covered top and bottom.
- Tracking HUD is moved to a bounded bottom card during cockpit tracking rather than covering the search/map center.

## CCTV popup
- Keeps the dedicated centered popup from v0.31.0, with more side margin on phones so the window can actually be dragged.
- Popup remains closable and live-analysis overlays stay attached to the currently selected CCTV.

## Search
- Strong unique partial matches from the local landmark catalog can resolve before remote geocoding.
- Metro/station and road-intersection query variants are prioritized, while Photon fallback now tries more normalized forms.
- Taipei 101 remains the fallback origin/center when precise location is unavailable.
